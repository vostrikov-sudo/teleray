# TeleRay 📡

Мессенджер с видео/аудио звонками, групповыми чатами и демонстрацией экрана.

## Технологии

- **Backend**: Node.js + Express + WebSocket (ws)
- **Realtime**: WebSocket для сообщений, статусов и сигналинга
- **Видео/Аудио**: WebRTC (mesh-архитектура, до 10 участников)
- **Auth**: JWT + bcrypt
- **Frontend**: Vanilla JS + CSS (без фреймворков)

## Запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
node server/index.js
```

Или с автоперезагрузкой (нужен `nodemon`):
```bash
npm run dev
```

Сервер запустится на **http://localhost:3000**

### 3. Тестирование звонков

Откройте **два разных браузера** (или вкладку + приватное окно):
- Браузер 1: войдите как `alex` / пароль `demo123`  
- Браузер 2: войдите как `maria` / пароль `demo123`
- Найдите друг друга через поиск → откройте чат → нажмите 📹 или 📞

## Функционал

### Аутентификация
- Регистрация (логин, имя, пароль ≥6 символов)
- Вход с JWT-сессией (30 дней)
- Демо-аккаунты: `alex`, `maria`, `ivan` / `demo123`

### Чаты
- Личные чаты — найти пользователя → сразу писать (без взаимного добавления)
- Групповые чаты (до 10 участников)
- Реальное время через WebSocket (без полинга!)
- Удаление своих сообщений (правый клик или кнопка 🗑)
- Отправка фото (лимит 5 МБ)
- Отправка файлов (лимит 10 МБ)
- Файлы удаляются через 24 часа
- Emoji-панель
- Индикатор печатания
- Бесконечная прокрутка вверх (подгрузка старых сообщений)
- Статусы прочтения (✓✓)

### Звонки (WebRTC)
- Аудио и видео звонки
- Групповые звонки до 10 человек (mesh)
- Включение/выключение микрофона и камеры
- Демонстрация экрана
- Таймер звонка
- Логирование звонков в истории чата

### Настройки
- Смена имени и аватарки
- Тема: светлая / тёмная
- Язык: 🇷🇺 Русский · 🇬🇧 English · 🇺🇦 Українська · 🇰🇿 Қазақша

## Production (опционально)

Для продакшена установите переменную окружения:
```bash
JWT_SECRET=ваш_секретный_ключ PORT=3000 node server/index.js
```

Данные хранятся in-memory. Для персистентности подключите SQLite или PostgreSQL.

## WebRTC за NAT

Если звонки не работают между разными сетями, добавьте TURN-сервер в `ICE` конфигурацию в `app.js`:
```js
ICE: {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'turn:ваш.turn.server', username: 'user', credential: 'pass' }
  ]
}
```
